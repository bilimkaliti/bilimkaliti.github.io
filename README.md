# Bilim Kaliti — sinf o‘yinlari boti

Telegram bot: o‘yinlarni Telegram ichida ochadi va javob kodlarini o‘qituvchiga yuboradi.

## Fayllar
- `app.py` — botning o‘zi
- `games/` — o‘yinlar: Sirli xonalar, Kosmik baza, Eshik kodi
- `requirements.txt`, `.python-version` — Render uchun sozlamalar

## Render’da ishga tushirish
- Build Command: `pip install -r requirements.txt`
- Start Command: `python app.py`
- Environment Variable: `BOT_TOKEN` = BotFather bergan token

Tokenni hech qachon fayllarga yoki GitHub’ga yozmang.
